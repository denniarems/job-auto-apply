Create useFieldMapping.ts:

```typescript
interface UseFieldMappingReturn {
  mappings: FieldMapping[];
  loading: boolean;
  error: string | null;
  detectForms: () => Promise<void>;
  extractFields: (forms: FormData[]) => Promise<void>;
  matchFields: (url?: string) => Promise<void>;
  updateMapping: (index: number, match: MemoryMatch) => void;
  addMemoryForField: (index: number, value: string, createMemory: boolean) => Promise<void>;
}
```

- detectForms: Send forms to API, get detection results
- extractFields: Send fields to API, get semantic categories
- matchFields: Send detected fields to API, get memory matches
- updateMapping: Update selected match for a field
- addMemoryForField: Create new memory for unmapped field

Create useAutoFill.ts:

```typescript
interface UseAutoFillReturn {
  isFilling: boolean;
  progress: FillProgress | null;
  startFill: (mappings: FieldMapping[]) => Promise<FillResult[]>;
  cancelFill: () => void;
}
```

- startFill: Send FILL_FIELDS message to content script, handle progress updates via listener
- cancelFill: Send CANCEL_FILL message
- Uses chrome.runtime.onMessage to receive fill progress updates
- Returns FillResult[] on completion

Per user decisions:
- AI matching for mapping
- Prompt user for unmapped fields
- Track usage and last_used timestamps (done in backend)
