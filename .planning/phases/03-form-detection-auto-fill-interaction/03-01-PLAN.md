  <files>apps/server/src/types/forms.ts</files>
  <action>
Create TypeScript interfaces for the form detection system:

```typescript
// Form field from DOM
export interface FormField {
  type: string;
  name: string;
  id: string;
  label: string;
  placeholder: string;
  required: boolean;
  autocomplete: string;
  cssHidden: boolean;
  maxLength?: number;
  pattern?: string;
}

// Form data from content script
export interface FormData {
  action: string;
  method: string;
  fields: FormField[];
  url: string;
  atsType?: 'greenhouse' | 'lever' | 'workday' | 'other';
}

// AI detection result
export interface DetectionResult {
  isJobApplication: boolean;
  confidence: number; // 0-1
  atsType: 'greenhouse' | 'lever' | 'workday' | 'other' | null;
  detectedFields: DetectedField[];
}

export interface DetectedField {
  category: 'personal' | 'contact' | 'experience' | 'education' | 'salary' | 'skills' | 'other';
  semanticName: string;
  inputName: string;
  memoryQuestion: string;
  keywords: string[];
}

// Field-to-memory mapping
export interface MemoryMatch {
  memoryId: string;
  question: string;
  answer: string;
  confidence: number; // 0-100
  source: 'memory' | 'resume' | 'manual';
}

export interface FieldMapping {
  field: FormField;
  detected: DetectedField;
  matches: MemoryMatch[];
  selectedMatch?: MemoryMatch;
  status: 'pending' | 'mapped' | 'unmapped' | 'failed';
  source?: 'memory' | 'resume' | 'manual' | 'skip';
}

// Fill result
export interface FillResult {
  field: FormField;
  success: boolean;
  skipped: boolean;
  error?: string;
  source?: 'memory' | 'resume' | 'manual';
}
```

Export all interfaces. Use exact naming as shown.

<task type="auto">
  <name>Task 4: Create field-to-memory mapping API route</name>
  <files>apps/server/src/routes/mappings.ts</files>
  <action>
Create apps/server/src/routes/mappings.ts:

**POST /api/mappings/match**
- Accept: { fields: DetectedField[], url?: string }
- For each field:
  1. Generate embedding for the field's memoryQuestion
  2. Search memoriesTable.vectorSearch() with limit=5
  3. Score matches: exact (>85%) = auto-match, borderline (60-85%) = include but mark for review, low (<60%) = skip
  4. Return all candidates with confidence percentages (0-100)
- Track usage: Update memory's usage_count and last_used when selected
- Many-to-one cardinality: Allow multiple memories to map to one field
- Response: { mappings: FieldMapping[] }

Per user decisions:
- Matching method: AI matching (interpret field and memory semantically)
- Confidence format: Percentage (0-100)
- Cardinality: Many-to-one
- Candidate display: Show all candidates
- Confidence display: Always show percentage
- Meaning-first: Prioritize semantic meaning over exact label match

Note: For borderline matches (60-85%), call AI verifyMatch function to confirm semantic alignment before including.
