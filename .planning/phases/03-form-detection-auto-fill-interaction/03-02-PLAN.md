  <name>Task 1: Create DOM utilities for field extraction</name>
  <files>apps/extension/utils/dom.ts</files>
  <action>
Create apps/extension/utils/dom.ts with utilities:

**extractForms(): FormData[]**
- Query all forms on page: document.querySelectorAll('form')
- For each form, extract action, method, and call extractFields()
- Return array of FormData

**extractFields(form: HTMLFormElement): FormField[]**
- Query inputs, selects, textareas: form.querySelectorAll('input, select, textarea')
- For each field extract: type, name, id, label (find via label[for], adjacent, or parent), placeholder, required, autocomplete, maxLength, pattern
- Compute cssHidden: Check computed style for display:none, visibility:hidden, opacity:0, or position off-screen (left < -1000)
- Return array of FormField

**findLabel(field: Element): string**
- Check label[for]=field.id
- Check field.ariaLabel
- Check adjacent label element
- Check parent label element
- Check closest .label, .field-label, [aria-label] elements
- Return empty string if not found

**querySelectorAllDeep(selector: string): Element[]**
- Walk shadow DOM: For each element with shadowRoot, recursively query
- Return all matching elements across all shadow boundaries

**getSurroundingText(element: Element): string**
- Get textContent from parent elements (limited depth)
- Useful for AI context

Per user decisions:
- Content-first analysis: Send DOM content, not screenshots
- All combined field identification: Use name + patterns + label + placeholder

<task type="auto">
  <name>Task 2: Create event simulation utilities</name>
  <files>apps/extension/utils/events.ts</files>
  <action>
Create apps/extension/utils/events.ts with React/Vue-compatible fill:

**fillField(element: HTMLElement, value: string): Promise<void>**
1. Focus: element.focus()
2. Clear existing value: element.value = '' (for input/textarea)
3. Character-by-character typing:
   - For each char: dispatch beforeinput (inputType: 'insertText', data: char)
   - Then element.value += char
   - Then dispatch input (inputType: 'insertText', data: char)
   - Delay 20-50ms between chars (random for human-like)
4. Dispatch change: new Event('change', { bubbles: true })
5. Blur: element.blur()

**fillSelect(select: HTMLSelectElement, value: string): Promise<void>**
- select.focus()
- select.value = value
- select.dispatchEvent(new Event('change', { bubbles: true }))
- select.dispatchEvent(new Event('blur', { bubbles: true }))

**setVisualIndicator(element: HTMLElement, status: 'filling' | 'success' | 'failed'): void**
- filling: outline='2px solid #3b82f6', borderColor='#3b82f6' (blue)
- success: outline='2px solid #22c55e', borderColor='#22c55e' (green)
- failed: outline='2px solid #ef4444', borderColor='#ef4444' (red)

**sleep(ms: number): Promise<void>**
- Utility for delays

Per user decisions:
- Fill method: Simulate typing character by character with delays
- Visual feedback: Focus on each field during fill
- Color coding: Green=filled, Red=failed
- React/Vue compatibility: Full event chain (focus, beforeinput, input, change, blur)
  </action>

<task type="auto">
  <name>Task 4: Implement content script with form scanning</name>
  <files>apps/extension/entrypoints/content.ts</files>
  <action>
Rewrite apps/extension/entrypoints/content.ts:

**Main Functions:**
1. **Message Handlers:**
   - DETECT_FORMS: Call scanAndDetectForms(), return results
   - FILL_FIELDS: Call executeFill(mappings), return results
   - GET_STATUS: Return current state

2. **scanAndDetectForms(): Promise<DetectionResult[]>**
   - Call extractForms() to get DOM form data
   - Send to background: { type: 'API_DETECT', forms, url: window.location.href }
   - Receive AI classification results
   - Update badge: chrome.action.setBadgeText (green for form found)
   - Return results

3. **executeFill(mappings: FieldMapping[]): Promise<FillResult[]>**
   - Filter out honeypot fields using isHoneypotField()
   - Filter out fields with existing values (skip if already filled)
   - Sequential fill: for each mapping, find element, call fillField()
   - Visual indicators: blue while filling, green/red after
   - Report per-field status to background
   - Return FillResult[]

4. **MutationObserver for dynamic forms:**
   - Observe document.body for childList/subtree changes
   - When new form detected, notify background (optional: auto-scan)

5. **Shadow DOM handling:**
   - Use querySelectorAllDeep for Workday and similar

**Message Types:**
```typescript
type ContentMessage =
  | { type: 'DETECT_FORMS' }
  | { type: 'FILL_FIELDS'; mappings: FieldMapping[] }
  | { type: 'GET_STATUS' }
  | { type: 'FORM_DETECTED'; form: FormData }
  | { type: 'HONEYPOT_SKIPPED'; field: FormField; reason: string }
```

Per user decisions:
- Trigger: Manual only (from extension popup)
- Fill order: Sequential in DOM order
- Skip existing: Yes, if field has value
- Cancel during fill: Need cancel button support
