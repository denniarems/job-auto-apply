# Phase 2: Resume Ingestion & AI Intelligence - Plan 02-01

## Overview
Implement PDF resume upload, AI extraction, and memory generation with multi-provider support.

## Requirements Covered
- RES-01: Support PDF resume uploads and extract text using AI-powered parsing
- RES-02: Automatically generate memories from extracted resume data
- RES-03: Allow users to review and edit extracted data before saving as memories
- AI-01: Support Claude, Gemini, and Qwen providers via Vercel AI SDK
- AI-02: Allow real-time switching between AI providers in extension settings
- FORM-04: Generate natural language questions for each identified field to facilitate memory matching

## Tasks

### Task 1: Server - PDF Parsing Library Setup
**File**: `apps/server/package.json`
- Add `pdf-parse` dependency for PDF text extraction

**Verification**: Package installs successfully with `bun install`

### Task 2: Server - Environment Variables for AI Providers
**File**: `packages/env/src/server.ts`
- Add `QWEEN_API_KEY` environment variable for Qwen provider support

**Verification**: Type and export available in server code

### Task 3: Server - PDF Parsing Library
**File**: `apps/server/src/lib/pdf.ts`
- Create PDF parsing utility using pdf-parse
- Handle file size validation (10MB limit)
- Handle password-protected and corrupted PDFs
- Return extracted text and metadata

**Verification**: Can parse sample PDF and return text

### Task 4: Server - AI Extraction Logic
**File**: `apps/server/src/lib/extraction.ts`
- Create Zod schema for resume data extraction
- Implement `extractResumeData` function using generateObject
- Support provider parameter for Claude/Gemini/Qwen selection
- Return extracted fields with confidence indicators

**Verification**: Returns structured resume object from PDF text

### Task 5: Server - Question Generation Logic
**File**: `apps/server/src/lib/questions.ts`
- Create schema for natural language questions
- Implement `generateFieldQuestions` function
- Generate questions for each extracted field category

**Verification**: Returns array of field questions

### Task 6: Server - Resume Routes
**File**: `apps/server/src/routes/resumes.ts`
- POST `/api/resumes/upload`: Accept PDF, extract data, return with questions
- POST `/api/resumes/approve`: Accept approved fields, create memories in Zvec
- GET `/api/resumes`: List uploaded resumes (in-memory for now)

**Verification**: Endpoints return expected data formats

### Task 7: Server - Provider Routes
**File**: `apps/server/src/routes/providers.ts`
- GET `/api/providers`: List available providers and their key status
- GET `/api/providers/config`: Get current provider selection
- PATCH `/api/providers/config`: Update selected provider

**Verification**: Returns provider status and handles selection

### Task 8: Server - Register Routes
**File**: `apps/server/src/index.ts`
- Import and register resumes router
- Import and register providers router

**Verification**: Routes accessible at /api/resumes/* and /api/providers/*

### Task 9: Extension - Resume Upload Component
**File**: `apps/extension/entrypoints/sidepanel/ResumeUpload.tsx`
- Drag and drop zone with file input fallback
- Upload button with loading state
- Progress indicator during upload
- Error handling UI for failed uploads

**Verification**: Component renders and accepts file drops

### Task 10: Extension - Resume Review Component
**File**: `apps/extension/entrypoints/sidepanel/ResumeReview.tsx`
- Structured form displaying extracted fields
- Editable fields with inline editing
- Confidence indicators per field
- Bulk "Save All to Memory" button
- Side panel showing existing memories for reference

**Verification**: Shows extracted data in editable form

### Task 11: Extension - Resume Tab Integration
**File**: `apps/extension/entrypoints/sidepanel/App.tsx`
- Integrate ResumeUpload and ResumeReview components
- Add API calls for upload and approve endpoints
- Handle loading and error states

**Verification**: Full flow from upload to memory creation works

### Task 12: Extension - Provider Switching in Settings
**File**: `apps/extension/entrypoints/sidepanel/App.tsx`
- Update settings tab with provider dropdown
- Show API key status (checkmark/X) per provider
- Persist selection to chrome.storage.local

**Verification**: Can switch provider and see status

## Must Haves (for goal-backward verification)

1. **PDF Upload Works**: User can drag/drop or click to upload a PDF resume
2. **Extraction Shows Data**: After upload, extracted fields (name, email, skills, etc.) display in review panel
3. **Fields Editable**: User can modify any extracted field before saving
4. **Memory Creation**: Clicking "Save All" creates memories in Zvec with questions
5. **Provider Switch Works**: Settings dropdown changes AI provider, next extraction uses new provider
6. **Questions Generated**: Each memory has a natural language question for vector matching
